# Расчёт рентабельности продуктов
В данном репозитории представлен пример доработки запросов к БД по расчёту рентабельности, а также файлы Excel объясняющие принцип работы данного механизма. 

**Архив имеет следующее содержимое:**
- fn_get_alternate_bonus.sql - SQL запрос на создание функции fn_get_alternate_bonus, используемой для расчёта процента бонуса по продукту в рамках расчёта рентабельности (функция GetProductRentabilityCalculation.sql) для нестандартных случаев (если не вычислили через fn_get_tender_bonus.sql)
- fn_get_business_unit.sql - SQL запрос на создание функции fn_get_business_unit, используемой для получения БЕ (Бизнес единицы) по указанному продукту
- fn_get_tender_bonus.sql - SQL запрос на создание функции fn_get_tender_bonus, используемой для расчёта процента бонуса по продукту в рамках расчёта рентабельности (функция GetProductRentabilityCalculation.sql) для стандартных случаев
- GetProductRentabilityCalculation.sql - Основной SQL запрос производящий расчёт показателей рентабельности по продуктам
- GetProductRentabilty.sql - SQL запрос, получающий данные из внешних БД по одиночному продукту и вызывающий функцию GetProductRentabilityCalculation.sql для расчёта рентабельности по нему
- GetProductSetRentability.sql - SQL запрос, получающий данные из внешних БД по множеству продуктам и вызывающий функцию GetProductRentabilityCalculation.sql для расчёта рентабельности по ним
- Описание расчетов рентабености CRM AS-IS - TO-BE.xlsx - Excel файл, содержащий описание доработок механизма расчёта рентабельности
