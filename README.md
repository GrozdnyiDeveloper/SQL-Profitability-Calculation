# Расчёт рентабельности продуктов
В данном репозитории представлены примеры доработки запросов к БД по расчёту рентабельности, проект по ручному запуску расчёта рентаельности, а также файлы Excel объясняющие принцип работы данного механизма. 

**Архив имеет следующее содержимое:**
- CalculatingFactProfitability - Проект, является консольным приложением для рчного запуска процесса массового расчета рентабельности Продуктов в CRM по Проектным скидкам и Заявкам Акций за последние 2 месяца (или за всё время при первом запуске)
- fn_get_alternate_bonus.sql - TSQL запрос на создание функции fn_get_alternate_bonus, используемой для расчёта процента бонуса по продукту в рамках расчёта рентабельности (функция GetProductRentabilityCalculation.sql) для нестандартных случаев (если не вычислили через fn_get_tender_bonus.sql)
- fn_get_business_unit.sql - TSQL запрос на создание функции fn_get_business_unit, используемой для получения БЕ (Бизнес единицы) по указанному продукту
- fn_get_tender_bonus.sql - TSQL запрос на создание функции fn_get_tender_bonus, используемой для расчёта процента бонуса по продукту в рамках расчёта рентабельности (функция GetProductRentabilityCalculation.sql) для стандартных случаев
- GetProductRentabilityCalculation.sql - Основной TSQL запрос производящий расчёт показателей рентабельности по продуктам
- GetProductRentabilty.sql - TSQL запрос, получающий данные из внешних БД по одиночному продукту и вызывающий функцию GetProductRentabilityCalculation.sql для расчёта рентабельности по нему
- GetProductSetRentability.sql - TSQL запрос, получающий данные из внешних БД по множеству продуктам и вызывающий функцию GetProductRentabilityCalculation.sql для расчёта рентабельности по ним
- Описание расчетов рентабености CRM AS-IS - TO-BE.xlsx - Excel файл, содержащий описание доработок механизма расчёта рентабельности
- Расходы для расчета рентабельности представление расширенного поиска 10-11-2025 17-19-07.xlsx - Excel файл, содержащий данные для записей новой сущности, используемой при расчёте рентабельности (перенос с DEV на PROD)
- Расходы для расчета рентабельности представление расширенного поиска 10-11-2025 17-19-07.csv - CSV файл, содержащий данные из файла "Расходы для расчета рентабельности представление расширенного поиска 10-11-2025 17-19-07.xlsx" в формате корректном для импорта в Dynamics 365 CRM
